Historical intelligence

A reliability layer with deliberate guardrails.

HorizonBias compares an original bias classification with later price direction using the ATR known at that time. It audits directional alignment—not simulated profit.

24h → 1ySwitch between five history windows and inspect overall agreement or one timeframe.
±0.25 ATRSmall subsequent movements are treated as neutral market noise.
20 samplesNo alignment percentage appears before the minimum mature sample size.
50 samplesSample quality is not labeled established until this larger threshold is reached.
Built to learn slowly

The scheduler evaluates newly mature observations every 15 minutes from stored candles. Both AIs receive calculated history summaries and must disclose when the evidence is still insufficient. Neither AI sees the heatmap image or modifies the deterministic score.

Architecture

Analysis happens away from visitor requests.

Scheduled commands collect evidence and persist validated results. Public pages only read stored state, keeping credentials private and provider outages away from the visitor path.

  1. 1
    Collect

    Fetch completed Twelve Data candles and verified official-feed events.

  2. 2
    Calculate

    Run local indicators, component scores, and weighted multi-timeframe agreement.

  3. 3
    Preserve and evaluate

    Capture canonical history and evaluate mature outcomes against stored future candles.

  4. 4
    Cross-check context

    Gemini and Groq independently interpret identical structured evidence.

  5. 5
    Present

    Serve the responsive dashboard, heatmap, chart, read-only JSON contracts, and a feature-detected Floating Bias Monitor with a standard popup fallback.

Development setup

Run HorizonBias locally.

Clone the repository, install dependencies, configure private provider keys in .env, initialize history, and start Laravel plus its scheduler.

git clone https://github.com/ivanleedorillo-ops/HorizonBias.git
cd HorizonBias
composer install
npm.cmd install
copy .env.example .env
php artisan key:generate
php artisan migrate
php artisan bias-history:backfill
php artisan bias-history:evaluate
npm.cmd run build
php artisan serve --host=127.0.0.1 --port=8088

# Run separately for automatic refreshes
php artisan schedule:work
