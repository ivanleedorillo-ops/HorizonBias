Core capabilities

Built for evidence, not instructions.

01

Seven timeframes

Technical conditions from 5 minutes through 1 month, with weighted higher-timeframe agreement.

02

Auditable scoring

EMA alignment, RSI, MACD, rate of change, confirmed pivots, and breakouts remain visible and testable.

03

Separate macro context

Gemini-generated context never changes or overrides the deterministic technical score.

04

Honest demo boundary

Illustrative fixtures are clearly labeled whenever live-data access or public-display licensing is unavailable.

Architecture

Providers stay outside visitor requests.

Scheduled commands collect and validate data, calculate snapshots, and store results. The public controller reads only persisted or cached state.

  1. 1
    Collect

    Twelve Data candles and optional grounded Gemini context.

  2. 2
    Validate and calculate

    Normalize completed candles and run local indicators.

  3. 3
    Persist

    Store candles, bias snapshots, and last-known-good briefs.

  4. 4
    Present

    Serve the responsive dashboard and read-only JSON contract.

Development setup

Run HorizonBias locally.

Clone the repository, install PHP and frontend dependencies, configure .env, then start Laravel.

git clone https://github.com/ivanleedorillo-ops/HorizonBias.git
cd HorizonBias
composer install
npm.cmd install
copy .env.example .env
php artisan key:generate
php artisan migrate
npm.cmd run build
php artisan serve

HorizonBias provides educational market context and technical bias only. It is not financial advice, a trading signal, or a recommendation to buy or sell.
